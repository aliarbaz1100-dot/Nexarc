Shortcuts Guide

NEXARC is built for fast instant play on desktop and mobile. These shortcuts help players search, open games and control the player faster.

Desktop keyboard shortcuts

  • / opens search instantly.
  • ESC closes the player or help overlay.
  • F enters fullscreen while a game is open.
  • R retries the current game.
  • N opens the next game.
  • T scrolls back to the top.

Mobile controls

On mobile, use the bottom navigation for Home, Search, My List, Random and Top. The install banner helps users add NEXARC to the home screen where supported.

Gameplay note

The 120-game catalog is source-verified. Hands-on gameplay QA remains the final step before custom domain launch.
